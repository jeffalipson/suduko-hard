# iOS App Implementation Plan (Plan 5 of 7)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A playable iPhone app: home screen (Classic/Killer × 7 tiers with resume), the NYT-style game screen (board with cages, Normal/Candidate input, number pad, undo/redo/erase, timer, pause, check/reveal), settings toggles, completion screen, a bundled puzzle library, and 14 always-full queues refilled in the background.

**Architecture:** Game logic lives in a new UI-free library target `SudokuGame` inside the `SudokuCore` package, so it's tested with `swift test` in seconds: `GameSession` (entries, notes, undo/redo, assists, check/reveal, timer, Codable autosave), `GameSettings`, `KillerHelper`, `PuzzleLibrary`, `PuzzleQueues`. The iOS app (`HardSudoku`, generated by XcodeGen from `project.yml`) is a thin SwiftUI layer: an `@Observable AppModel` persists one JSON state file, owns the queues, and runs background generation; views render a `GameSession`. Hints (Plan 6) and Stats (Plan 7) get placeholders.

**Tech Stack:** Swift 6.2, SwiftUI (iOS 17+), Observation, BackgroundTasks, XcodeGen, Swift Testing, XCUITest.

**Spec:** `docs/superpowers/specs/2026-10-10-hard-sudoku-design.md` (§5.3–5.5, §6)

## Global Constraints

- iOS 17+, iPhone, portrait. Swift 6 language mode.
- Settings (spec §6.3) and their defaults: auto-candidates Off, auto-remove candidates Off, mistake highlighting Off, Killer cage helper Off, Killer remaining sum Off, highlight matching **On**. When a setting is off its UI is hidden.
- Mistakes are counted only while mistake highlighting is on.
- Clean solve = won with zero hints, checks, reveals and assists (auto-candidates, cage helper).
- One unfinished game per mode × tier; starting a new game there abandons the old one.
- Queues: 14 (mode × tier), kept at 3; library draw order shuffled once per install, no repeats until exhausted; every queued puzzle gets a random `GridTransform` (Killer: no digit relabelling).
- Spec deviation (ruled here, amended in Task 6): saved games and queues persist as one Codable JSON file; SwiftData is used for stats only (Plan 7).

## Review Focus

1. **Undo/redo across every mutation** (digit, note, erase, auto-candidates, reveal) → exact restore; redo cleared by a new action. Task 2 tests.
2. **Givens are immutable** (input, erase, reveal on a given) → no change, no undo entry. Task 1 tests.
3. **Queue never empty on start** → every key refills from the library before first use; library exhaustion reshuffles. Task 4 tests.
4. **Autosave round-trip** (session mid-game, paused, with undo history) → identical after decode. Task 2 test.
5. **Timer** → only advances while not paused and not complete. Task 2 test.

```swift
import SudokuCore

public enum InputMode: String, Codable, Sendable {
    case normal, candidate
}

/// Everything a finished game reports to stats.
public struct AssistLog: Codable, Equatable, Sendable {
    /// Wrong digits entered while mistake highlighting was on.
    public var mistakes = 0
    public var checks = 0
    public var reveals = 0
    public var autoCandidates = 0
    public var cageHelper = 0
    /// Hint uses by level name (Plan 6).
    public var hints: [String: Int] = [:]

    public init() {}

    public var isClean: Bool {
        checks == 0 && reveals == 0 && autoCandidates == 0 && cageHelper == 0 && hints.values.allSatisfy { $0 == 0 }
    }
}

public struct GameSession: Codable, Equatable, Sendable {
    struct Snapshot: Codable, Equatable, Sendable {
        let entries: [Int]
        let notes: [CandidateSet]
    }

    public let puzzle: Puzzle
    public private(set) var entries: [Int]
    public private(set) var notes: [CandidateSet]
    public var selected: Int?
    public var inputMode: InputMode = .normal
    public private(set) var elapsed: Double = 0
    public private(set) var isPaused = false
    public internal(set) var log = AssistLog()
    /// Cells a Check flagged as wrong; cleared when the cell changes.
    public private(set) var flaggedWrong: Set<Int> = []
    var undoStack: [Snapshot] = []
    var redoStack: [Snapshot] = []

    public init(puzzle: Puzzle) {
        self.puzzle = puzzle
        self.entries = puzzle.givens
        self.notes = Array(repeating: .empty, count: 81)
    }

    public func isGiven(_ cell: Int) -> Bool { puzzle.givens[cell] != 0 }
    public func isWrong(_ cell: Int) -> Bool { entries[cell] != 0 && entries[cell] != puzzle.solution[cell] }
    public var isComplete: Bool { entries == puzzle.solution }
    public func placedCount(of digit: Int) -> Int { entries.filter { $0 == digit }.count }
    public var canUndo: Bool { !undoStack.isEmpty }
    public var canRedo: Bool { !redoStack.isEmpty }

    /// Normal mode places (or clears, if repeated) a digit; candidate mode toggles a note.
    public mutating func input(_ digit: Int, settings: GameSettings) {
        guard let cell = selected, !isGiven(cell), !isComplete else { return }
        switch inputMode {
        case .normal:
            record()
            if entries[cell] == digit {
                entries[cell] = 0
            } else {
                entries[cell] = digit
                notes[cell] = .empty
                if settings.mistakeHighlighting && digit != puzzle.solution[cell] { log.mistakes += 1 }
                if settings.autoRemoveCandidates { removeNote(digit, around: cell) }
            }
            flaggedWrong.remove(cell)
        case .candidate:
            guard entries[cell] == 0 else { return }
            record()
            if notes[cell].contains(digit) { notes[cell].remove(digit) } else { notes[cell].insert(digit) }
        }
    }

    /// Clears the selected cell's digit, or its notes when it has no digit.
    public mutating func erase() {
        guard let cell = selected, !isGiven(cell), entries[cell] != 0 || !notes[cell].isEmpty else { return }
        record()
        if entries[cell] != 0 { entries[cell] = 0 } else { notes[cell] = .empty }
        flaggedWrong.remove(cell)
    }

    mutating func removeNote(_ digit: Int, around cell: Int) {
        for p in Geometry.peers[cell] { notes[p].remove(digit) }
        if let cage = puzzle.cages.first(where: { $0.cells.contains(cell) }) {
            for p in cage.cells where p != cell { notes[p].remove(digit) }
        }
    }

    /// Saves the current state for undo and clears redo.
    mutating func record() {
        undoStack.append(Snapshot(entries: entries, notes: notes))
        redoStack.removeAll()
    }

    mutating func restore(_ s: Snapshot) {
        entries = s.entries
        notes = s.notes
    }
}
```

```swift
import SudokuCore

extension GameSession {
    public mutating func undo() {
        guard let previous = undoStack.popLast() else { return }
        redoStack.append(Snapshot(entries: entries, notes: notes))
        restore(previous)
    }

    public mutating func redo() {
        guard let next = redoStack.popLast() else { return }
        undoStack.append(Snapshot(entries: entries, notes: notes))
        restore(next)
    }

    /// Fills every empty cell's notes with its true candidates (an assist).
    public mutating func fillAllCandidates() {
        guard !isComplete else { return }
        record()
        let board = Board(values: entries, cages: puzzle.cages)
        var filled = notes
        for c in 0..<81 { filled[c] = entries[c] == 0 ? board.candidates[c] : .empty }
        restore(Snapshot(entries: entries, notes: filled))
        log.autoCandidates += 1
    }

    /// Flags the selected cell if it's wrong.
    public mutating func checkCell() {
        guard let cell = selected else { return }
        log.checks += 1
        if isWrong(cell) { flag([cell]) }
    }

    /// Flags every wrong cell.
    public mutating func checkPuzzle() {
        log.checks += 1
        flag((0..<81).filter(isWrong))
    }

    /// Fills the selected cell with its solution digit.
    public mutating func revealCell() {
        guard let cell = selected, !isGiven(cell), entries[cell] != puzzle.solution[cell] else { return }
        record()
        var e = entries
        e[cell] = puzzle.solution[cell]
        var n = notes
        n[cell] = .empty
        restore(Snapshot(entries: e, notes: n))
        unflag(cell)
        log.reveals += 1
    }

    /// Advances the clock while the game is running.
    public mutating func tick(_ seconds: Double) {
        guard !isPaused, !isComplete else { return }
        addElapsed(seconds)
    }
}
```

```swift
import SudokuCore

public struct CageCombination: Equatable, Sendable {
    public let digits: [Int]
    public let possible: Bool
}

extension GameSession {
    public func cageIndex(of cell: Int) -> Int? {
        puzzle.cages.firstIndex { $0.cells.contains(cell) }
    }

    /// The cage total minus the digits entered in it.
    public func remainingSum(ofCage index: Int) -> Int {
        let cage = puzzle.cages[index]
        return cage.sum - cage.cells.map { entries[$0] }.reduce(0, +)
    }

    /// Every set of distinct digits that fills the cage; impossible when it lacks an entered digit.
    public func combinations(ofCage index: Int) -> [CageCombination] {
        let cage = puzzle.cages[index]
        let entered = Set(cage.cells.map { entries[$0] }.filter { $0 != 0 })
        var out: [[Int]] = []
        func go(_ from: Int, _ left: Int, _ acc: [Int]) {
            if acc.count == cage.cells.count {
                if left == 0 { out.append(acc) }
                return
            }
            guard from <= 9 else { return }
            for d in from...9 where d <= left { go(d + 1, left - d, acc + [d]) }
        }
        go(1, cage.sum, [])
        return out.map { CageCombination(digits: $0, possible: entered.isSubset(of: $0)) }
    }

    /// Records that the cage helper was opened (counted once per game).
    public mutating func useCageHelper() {
        if log.cageHelper == 0 { log.cageHelper = 1 }
    }
}
```

```swift
public struct QueueKey: Hashable, Codable, Sendable {

    public let tier: Tier

        self.mode = mode
        self.tier = tier

    public static let all: [QueueKey] = Mode.allCases.flatMap { m in Tier.allCases.map { QueueKey(mode: m, tier: $0) } }
}

/// The bundled, pre-generated puzzles.
public struct PuzzleLibrary: Sendable {
    public let puzzles: [QueueKey: [Puzzle]]

    public init(puzzles: [QueueKey: [Puzzle]]) {
        self.puzzles = puzzles
    }

    /// Reads `<key.name>.json` for every key in `directory`; missing or unreadable files count as empty.
    public static func load(from directory: URL) -> PuzzleLibrary {
        var out: [QueueKey: [Puzzle]] = [:]
        for key in QueueKey.all {
            let url = directory.appendingPathComponent("\(key.name).json")
            if let data = try? Data(contentsOf: url), let list = try? JSONDecoder().decode([Puzzle].self, from: data) {
                out[key] = list
            }
        }
        return PuzzleLibrary(puzzles: out)
    }
}
```

```swift
import SudokuCore

/// Ready-to-play puzzles per mode × tier, kept topped up to `target`.
public struct PuzzleQueues: Codable, Equatable, Sendable {
    public static let target = 3

    var ready: [String: [Puzzle]] = [:]
    /// Shuffled library indices per key and how far into them we are.
    var order: [String: [Int]] = [:]
    var cursor: [String: Int] = [:]

    public init() {}

    public func count(_ key: QueueKey) -> Int { ready[key.name, default: []].count }
    public func deficit(_ key: QueueKey) -> Int { max(0, Self.target - count(key)) }

    public mutating func pop(_ key: QueueKey) -> Puzzle? {
        guard !ready[key.name, default: []].isEmpty else { return nil }
        return ready[key.name]!.removeFirst()
    }

    /// Adds a puzzle after giving it a fresh random look.
    public mutating func push<R: RandomNumberGenerator>(_ puzzle: Puzzle, for key: QueueKey, using rng: inout R) {
        let transformed = GridTransform.random(for: puzzle, using: &rng).apply(to: puzzle)
        ready[key.name, default: []].append(transformed)
    }

    /// Tops `key` up from the library in this install's shuffled order, reshuffling when exhausted.
    public mutating func refillFromLibrary<R: RandomNumberGenerator>(_ key: QueueKey, library: PuzzleLibrary, using rng: inout R) {
        let pool = library.puzzles[key] ?? []
        guard !pool.isEmpty else { return }
        while deficit(key) > 0 {
            var indices = order[key.name] ?? []
            var at = cursor[key.name] ?? 0
            if indices.count != pool.count || at >= indices.count {
                indices = Array(pool.indices).shuffled(using: &rng)
                at = 0
            }
            push(pool[indices[at]], for: key, using: &rng)
            order[key.name] = indices
            cursor[key.name] = at + 1
        }
    }

    public mutating func fillAllFromLibrary<R: RandomNumberGenerator>(_ library: PuzzleLibrary, using rng: inout R) {
        for key in QueueKey.all { refillFromLibrary(key, library: library, using: &rng) }
    }
}
```

```swift
/// Everything the app keeps between launches, saved as one JSON file.
struct SavedState: Codable {
    var settings = GameSettings()
    var queues = PuzzleQueues()
    var games: [String: GameSession] = [:]
}

enum Persistence {
    static var url: URL {
        let dir = FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        return dir.appendingPathComponent("state.json")
    }

    static func load() -> SavedState {
        guard let data = try? Data(contentsOf: url), let state = try? JSONDecoder().decode(SavedState.self, from: data) else {
            return SavedState()
        }
        return state
    }

    static func save(_ state: SavedState) {
        guard let data = try? JSONEncoder().encode(state) else { return }
        try? data.write(to: url, options: .atomic)
    }
}
```

`App/AppModel.swift`:
```swift
import Foundation
import Observation
import SudokuCore
import SudokuGame

@Observable @MainActor
final class AppModel {
    var settings: GameSettings { didSet { save() } }
    private(set) var queues: PuzzleQueues
    private(set) var games: [String: GameSession]
    let library: PuzzleLibrary
    private var rng = SystemRandomNumberGenerator()
    private var refilling = false

    init() {
        let state = Persistence.load()
        settings = state.settings
        queues = state.queues
        games = state.games
        library = PuzzleLibrary.load(from: Bundle.main.resourceURL!)
        // Nothing should ever wait: top every queue up from the library right away.
        queues.fillAllFromLibrary(library, using: &rng)
        save()
    }

    func resumable(_ key: QueueKey) -> GameSession? { games[key.name] }

    /// Starts a fresh game, abandoning any unfinished one for this key.
    func startNew(_ key: QueueKey) -> GameSession? {
        if queues.count(key) == 0 { queues.refillFromLibrary(key, library: library, using: &rng) }
        guard let puzzle = queues.pop(key) else { return nil }
        let session = GameSession(puzzle: puzzle)
        games[key.name] = session
        save()
        Task { await refillLoop() }
        return session
    }

    func update(_ session: GameSession, for key: QueueKey) {
        games[key.name] = session
        save()
    }

    func finish(_ session: GameSession, for key: QueueKey) {
        games[key.name] = nil
        save()
    }

    func save() {
        Persistence.save(SavedState(settings: settings, queues: queues, games: games))
    }

    /// Tops queues up with freshly generated puzzles (falling back to the library) off the main actor.
    func refillLoop() async {
        guard !refilling else { return }
        refilling = true
        defer { refilling = false }
        for key in QueueKey.all where queues.deficit(key) > 0 {
            let generated = await Task.detached(priority: .background) { () -> Puzzle? in
                var rng = SystemRandomNumberGenerator()
                let deadline = ContinuousClock.now + .seconds(60)
                switch key.mode {
                case .classic: return ClassicGenerator().generate(tier: key.tier, using: &rng, deadline: deadline)
                case .killer: return KillerGenerator().generate(tier: key.tier, using: &rng, deadline: deadline)
                }
            }.value
            if let generated {
                queues.push(generated, for: key, using: &rng)
            } else {
                queues.refillFromLibrary(key, library: library, using: &rng)
            }
            save()
        }
    }
}
```

```swift
import SwiftUI
```
```swift
import SudokuCore
```

```swift
/// The 9×9 grid: highlights, digits, notes, Killer cages and grid lines, drawn in one Canvas.
struct BoardView: View {
    let session: GameSession
    let settings: GameSettings
    let onTap: (Int) -> Void

    var body: some View {
        GeometryReader { geo in
            let size = min(geo.size.width, geo.size.height)
            Canvas { ctx, _ in draw(in: &ctx, side: size) }
                .frame(width: size, height: size)
                .contentShape(Rectangle())
                .gesture(SpatialTapGesture().onEnded { tap in
                    let cell = size / 9
                    let r = min(8, max(0, Int(tap.location.y / cell)))
                    let c = min(8, max(0, Int(tap.location.x / cell)))
                    onTap(r * 9 + c)
                })
                .accessibilityIdentifier("board")
        }
        .aspectRatio(1, contentMode: .fit)
    }

    private func rect(_ cell: Int, _ unit: CGFloat) -> CGRect {
        CGRect(x: CGFloat(cell % 9) * unit, y: CGFloat(cell / 9) * unit, width: unit, height: unit)
    }

    private func draw(in ctx: inout GraphicsContext, side: CGFloat) {
        let unit = side / 9
        ctx.fill(Path(CGRect(x: 0, y: 0, width: side, height: side)), with: .color(Color(.systemBackground)))

        // Highlights.
        if let sel = session.selected {
            let digit = session.entries[sel]
            for c in 0..<81 {
                var fill: Color?
                if settings.highlightMatching && Geometry.sees(sel, c) { fill = Theme.related }
                if settings.highlightMatching && digit != 0 && session.entries[c] == digit { fill = Theme.sameDigit }
                if c == sel { fill = Theme.selected }
                if let fill { ctx.fill(Path(rect(c, unit)), with: .color(fill)) }
            }
        }
        for c in session.flaggedWrong { ctx.fill(Path(rect(c, unit)), with: .color(Theme.wrongFill)) }

        // Cages.
        if !session.puzzle.cages.isEmpty { drawCages(in: &ctx, unit: unit) }

        // Digits and notes.
        for c in 0..<81 {
            let r = rect(c, unit)
            let v = session.entries[c]
            if v != 0 {
                let wrong = settings.mistakeHighlighting && session.isWrong(c)
                let color = session.isGiven(c) ? Theme.given : (wrong ? Theme.wrong : Theme.entry)
                let text = Text("\(v)").font(.system(size: unit * 0.58, weight: session.isGiven(c) ? .semibold : .regular)).foregroundStyle(color)
                ctx.draw(text, at: CGPoint(x: r.midX, y: r.midY + (session.puzzle.cages.isEmpty ? 0 : unit * 0.06)))
            } else {
                for d in session.notes[c].digits {
                    let col = CGFloat((d - 1) % 3), row = CGFloat((d - 1) / 3)
                    let inset = session.puzzle.cages.isEmpty ? unit * 0.06 : unit * 0.14
                    let w = (unit - 2 * inset) / 3
                    let p = CGPoint(x: r.minX + inset + w * (col + 0.5), y: r.minY + inset + w * (row + 0.5))
                    ctx.draw(Text("\(d)").font(.system(size: unit * 0.22)).foregroundStyle(Theme.note), at: p)
                }
            }
        }

        // Grid lines.
        for i in 0...9 {
            let x = CGFloat(i) * unit
            let width: CGFloat = i % 3 == 0 ? 2 : 0.5
            var v = Path(); v.move(to: CGPoint(x: x, y: 0)); v.addLine(to: CGPoint(x: x, y: side))
            var h = Path(); h.move(to: CGPoint(x: 0, y: x)); h.addLine(to: CGPoint(x: side, y: x))
            ctx.stroke(v, with: .color(.primary.opacity(i % 3 == 0 ? 0.9 : 0.35)), lineWidth: width)
            ctx.stroke(h, with: .color(.primary.opacity(i % 3 == 0 ? 0.9 : 0.35)), lineWidth: width)
        }
    }

    private func drawCages(in ctx: inout GraphicsContext, unit: CGFloat) {
        let inset = unit * 0.08
        let style = StrokeStyle(lineWidth: 1, dash: [3, 2.5])
        for (i, cage) in session.puzzle.cages.enumerated() {
            let members = Set(cage.cells)
            var path = Path()
            for c in cage.cells {
                let r = rect(c, unit)
                let up = c >= 9 && members.contains(c - 9)
                let down = c < 72 && members.contains(c + 9)
                let left = c % 9 > 0 && members.contains(c - 1)
                let right = c % 9 < 8 && members.contains(c + 1)
                let x0 = left ? r.minX : r.minX + inset, x1 = right ? r.maxX : r.maxX - inset
                let y0 = up ? r.minY : r.minY + inset, y1 = down ? r.maxY : r.maxY - inset
                if !up { path.move(to: CGPoint(x: x0, y: r.minY + inset)); path.addLine(to: CGPoint(x: x1, y: r.minY + inset)) }
                if !down { path.move(to: CGPoint(x: x0, y: r.maxY - inset)); path.addLine(to: CGPoint(x: x1, y: r.maxY - inset)) }
                if !left { path.move(to: CGPoint(x: r.minX + inset, y: y0)); path.addLine(to: CGPoint(x: r.minX + inset, y: y1)) }
                if !right { path.move(to: CGPoint(x: r.maxX - inset, y: y0)); path.addLine(to: CGPoint(x: r.maxX - inset, y: y1)) }
            }
            ctx.stroke(path, with: .color(Theme.cage), style: style)
            let anchor = rect(cage.cells.min()!, unit)
            var label = "\(cage.sum)"
            if settings.remainingSum {
                let left = session.remainingSum(ofCage: i)
                if left != cage.sum { label += "·\(left)" }
            }
            let text = Text(label).font(.system(size: unit * 0.2, weight: .semibold)).foregroundStyle(.primary)
            ctx.draw(text, at: CGPoint(x: anchor.minX + inset + 1, y: anchor.minY + inset + 1), anchor: .topLeading)
        }
    }
}
```

```swift
import SwiftUI
import SudokuCore
import SudokuGame

struct GameView: View {
    let key: QueueKey
    @Environment(AppModel.self) private var model
    @Environment(\.dismiss) private var dismiss
    @Environment(\.scenePhase) private var phase
    @State private var session: GameSession?
    @State private var showCageHelper = false
    @State private var showCompletion = false
    private let timer = Timer.publish(every: 1, on: .main, in: .common).autoconnect()

    var body: some View {
        Group {
            if let binding = Binding($session) {
                content(binding)
            } else {
                ProgressView()
            }
        }
        .onAppear { session = model.resumable(key) }
        .onReceive(timer) { _ in
            guard phase == .active, var s = session else { return }
            s.tick(1)
            session = s
            if Int(s.elapsed) % 5 == 0 { model.update(s, for: key) }
        }
        .onChange(of: phase) { _, new in
            if new != .active, var s = session { s.setPaused(true); session = s; model.update(s, for: key) }
        }
    }

    @ViewBuilder
    private func content(_ s: Binding<GameSession>) -> some View {
        VStack(spacing: 16) {
            ZStack {
                BoardView(session: s.wrappedValue, settings: model.settings) { cell in
                    s.wrappedValue.selected = cell
                }
                .opacity(s.wrappedValue.isPaused ? 0 : 1)
                if s.wrappedValue.isPaused {
                    Button {
                        s.wrappedValue.setPaused(false)
                    } label: {
                        Label("Resume", systemImage: "play.fill").font(.title2)
                    }
                    .accessibilityIdentifier("resumeButton")
                }
            }
            .padding(.horizontal, 8)
            ControlsView(session: s, settings: model.settings, onChange: { changed(s.wrappedValue) }, showCageHelper: $showCageHelper)
                .padding(.horizontal, 12)
                .disabled(s.wrappedValue.isPaused)
            Spacer(minLength: 0)
        }
        .navigationTitle("\(key.mode.rawValue.capitalized) · \(key.tier.name.capitalized)")
        .navigationBarTitleDisplayMode(.inline)
        .toolbar {
            ToolbarItem(placement: .principal) {
                Text(Self.clock(s.wrappedValue.elapsed)).monospacedDigit().font(.headline).accessibilityIdentifier("clock")
            }
            ToolbarItemGroup(placement: .topBarTrailing) {
                Button(s.wrappedValue.isPaused ? "Resume" : "Pause", systemImage: s.wrappedValue.isPaused ? "play.fill" : "pause.fill") {
                    s.wrappedValue.setPaused(!s.wrappedValue.isPaused)
                    model.update(s.wrappedValue, for: key)
                }
                .accessibilityIdentifier("pauseButton")
                Menu {
                    Button("Check Cell") { s.wrappedValue.checkCell(); changed(s.wrappedValue) }
                    Button("Check Puzzle") { s.wrappedValue.checkPuzzle(); changed(s.wrappedValue) }
                    Button("Reveal Cell") { s.wrappedValue.revealCell(); changed(s.wrappedValue) }
                } label: { Image(systemName: "ellipsis.circle") }
                .accessibilityIdentifier("gameMenu")
            }
        }
        .sheet(isPresented: $showCageHelper) { CageHelperView(session: s.wrappedValue) }
        .sheet(isPresented: $showCompletion) {
            CompletionView(session: s.wrappedValue, mistakesCounted: model.settings.mistakeHighlighting) {
                showCompletion = false
                dismiss()
            }
            .interactiveDismissDisabled()
        }
    }

    private func changed(_ s: GameSession) {
        if s.isComplete {
            model.finish(s, for: key)
            UINotificationFeedbackGenerator().notificationOccurred(.success)
            showCompletion = true
        } else {
            model.update(s, for: key)
            UIImpactFeedbackGenerator(style: .light).impactOccurred()
        }
    }

    static func clock(_ seconds: Double) -> String {
        let s = Int(seconds)
        return s >= 3600 ? String(format: "%d:%02d:%02d", s / 3600, s / 60 % 60, s % 60) : String(format: "%d:%02d", s / 60, s % 60)
    }
}
```
