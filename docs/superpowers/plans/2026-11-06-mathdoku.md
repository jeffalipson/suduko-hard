# Mathdoku Mode Plan

**Goal:** A third tab, Mathdoku (N×N Latin square with arithmetic cages), at the app's seven tiers, with hints, lessons, Auto Pencil (cage-aware), colouring, stats and the same "every puzzle solvable by logic, graded by the hardest technique" guarantee.

**Background:** `reports/Really hard Mathdoku mode.md` (research, not committed) and the Python spike that generated the test puzzles (24 puzzles; 9×9 top tier 44–254 s each in Python).

**Architecture:** A separate Mathdoku engine in `SudokuCore/Sources/SudokuCore/Mathdoku/` and game layer in `SudokuCore/Sources/SudokuGame/Mathdoku/`, so the live Classic and Killer engines (9×9 `Geometry`, `Board`, `TechniqueID`, `Mode`) are untouched. The app reuses `ControlsView`, colouring, `NoteGrid` and the screen layouts through a small `PlayableSession` protocol; Mathdoku gets its own board view, hint bar and lesson sheet.

## Rules (as shipped)
- Digits 1…N, no repeats in a row or column. No boxes.
- Cages: + and × of any size; − and ÷ only on two-cell cages (bigger first); single-cell cages are givens.
- A digit may repeat in a cage if the copies are in different rows and columns.
- Nightmare hides the operation (only the target shows).

## Tiers
| Tier | Grid | Hardest technique required |
|---|---|---|
| Easy | 5×5 | L1: singles, cage arithmetic |
| Medium | 6×6 | L2: + cage-forced digits in a line, naked/hidden pairs and triples |
| Hard | 7×7 | L3: + X-Wing / Swordfish, two-cage combinations |
| Expert | 8×8 | L3 |
| Fiendish | 9×9 | L3 |
| Diabolical | 9×9 | L4: + contradiction (≥ 2 steps) |
| Nightmare | 9×9, hidden operations | L4 (≥ 1 step) |

## Tasks
1. **Model** — `MathOp`, `MathCage` (`satisfies`, `fillings(candidates:)`, `possibleDigits(n:)`), `MathdokuPuzzle` (Codable, compact), `MathdokuBoard`.
2. **Techniques, solver, grader** — `MathTechnique` (id, level, name), `MathStep`, `MathdokuSolver.nextStep`, `MathdokuGrader.grade` → level, tier.
3. **Generator + CLI** — `MathdokuGenerator.generate(tier:using:deadline:)`, `sudoku-forge --mode mathdoku`.
4. **Library** — 50 puzzles per tier in `App/Library/mathdoku-<tier>.json`; lower tiers also generated on device.
5. **Game session** — `MathdokuSession`: entries, notes, Auto Pencil (row/column + cage arithmetic), colours, undo/redo, check/reveal, keyboard movement, VoiceOver text.
6. **Hints and lessons** — `MathdokuHintEngine.diagnose`, graduated hint text, lesson text per technique with "show me on my board".
7. **App** — `PlayableSession` protocol for `ControlsView`; `MathdokuBoardView`; `MathdokuGameView`; Home third mode with tier ladder; `AppModel` queues/persistence; Stats.
8. **Verification** — unit tests per task, UI tests (play a Mathdoku game, hint, colour), screenshots on iPhone and iPad, PR.

Each task is test-first; the full unit and UI suites must stay green for Classic and Killer throughout.
