# iPad Version (1.1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Really Really Hard Sudoku 1.1 as a native iPhone + iPad app whose game and home screens adapt to any window size, with hardware-keyboard play.

**Architecture:** Layout decisions and keyboard mapping are pure functions in the `SudokuGame` package (unit-tested with Swift Testing). The SwiftUI views in `App/Views` read the space they are given (`GeometryReader`), ask those functions which arrangement to use, and reuse the existing components. iPhone keeps today's layout because its windows always choose the stacked / single-column arrangement.

**Tech Stack:** Swift 6, SwiftUI (iOS 17+), Swift Testing (`SudokuCore/Tests`), XCTest UI tests (`UITests/`), xcodegen (`project.yml`).

**Spec:** `docs/superpowers/specs/2026-10-13-ipad-design.md`

## Global Constraints

- iOS / iPadOS 17.0 minimum (unchanged). Device family iPhone + iPad (`TARGETED_DEVICE_FAMILY: "1,2"`).
- iPhone stays portrait-only; iPad supports all four orientations; no `UIRequiresFullScreen`.
- `MARKETING_VERSION` "1.1"; `CURRENT_PROJECT_VERSION` "3" (build 2 is the last upload).
- Bundle ID `com.jeffreylipson.hardsudoku`, App Store record, privacy answers: unchanged.
- iPhone layout and behaviour must not change. The existing 8 UI tests must keep passing on iPhone 17.
- Game side-by-side column: **340 pt** wide; side-by-side only when width ≥ height, height ≥ 600, and board `min(height − 32, width − 340 − 48)` ≥ 360.
- Stacked game controls capped at **560 pt** in regular-width windows. Game controls scale **1.3×** in regular width.
- Home: two columns when width > height and width ≥ 900; otherwise single column capped at **700 pt** in regular width. Home scales about **1.4×** in regular width.
- Keys: arrows move (stop at edges; no selection → r1c1), 1–9 digit, Delete/Backspace erase, Space toggle Normal/Candidate, ⌘Z undo, ⇧⌘Z redo. Game screen only; ignored while paused or a sheet is open.
- Out of scope: Apple Pencil features, sidebar navigation, new gameplay.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Commands used throughout**
- Unit tests: `swift test -c release --package-path SudokuCore` (debug is ~10× slower).
- Regenerate the Xcode project after any `project.yml` change: `xcodegen generate`.
- UI tests on iPhone: `xcodebuild -project HardSudoku.xcodeproj -scheme HardSudoku -destination 'platform=iOS Simulator,name=iPhone 17' test CODE_SIGNING_ALLOWED=NO`
- UI tests on iPad: same with `-destination 'platform=iOS Simulator,name=iPad Pro 11-inch (M5)'`.
- Debug launch flags (DEBUG builds): `-open <mode-tier>`, `-new`, `-auto`, `-uitest`, `-stats`, `-lesson <id>`, `-explain <id>`, `-killer`.

## Review Focus

1. **Keys while paused** — the board is hidden; pressing a digit must not change the game. Pinned in Task 4 (UI test `testKeysIgnoredWhilePaused`).
2. **Keyboard after a sheet closes** — after the lesson or cage-helper sheet is dismissed, keys must work again without tapping the board. Pinned in Task 4 (UI test `testKeysWorkAfterSheetCloses`).

/// How the game screen arranges the board and controls in the space it gets.
public enum GameLayout: Equatable, Sendable {
    /// Board above the controls (portrait, narrow windows, every iPhone).
    case stacked
    /// Board on the left at `board` points square, controls in a column on the right.
    case sideBySide(board: Double)

    /// Width of the controls column beside the board.
    public static let columnWidth: Double = 340
    /// Smallest board worth putting beside the controls (about an iPhone board).
    static let minimumBoard: Double = 360
    /// Height the controls column needs.
    static let minimumHeight: Double = 600

    /// `width` × `height` is the space below the navigation bar.
    public static func choose(width: Double, height: Double) -> GameLayout {
        guard width >= height, height >= minimumHeight else { return .stacked }
        // 16 pt padding top and bottom; 16 pt left, between and right.
        let board = min(height - 32, width - columnWidth - 48)
        return board >= minimumBoard ? .sideBySide(board: board) : .stacked
    }
}

/// How the home screen arranges its sections.
public enum HomeLayout: Equatable, Sendable {
    case singleColumn, twoColumns

    public static func choose(width: Double, height: Double) -> HomeLayout {
        width > height && width >= 900 ? .twoColumns : .singleColumn
    }
}
```

    /// Arrow-key movement: one cell at a time, stopping at the board's edges.
    /// With nothing selected, any move selects the top-left cell.
    public mutating func moveSelection(rows: Int, columns: Int) {
        guard let cell = selected else { selected = 0; return }
        let r = min(8, max(0, cell / 9 + rows))
        let c = min(8, max(0, cell % 9 + columns))
        selected = r * 9 + c
    }
```

Create `KeyCommand.swift`:

```swift
/// A hardware-keyboard key, reduced to what the game cares about.
public enum GameKey: Equatable, Sendable {
    case up, down, left, right, delete
    /// The characters the key produced (digits, space, …).
    case text(String)
}

public enum GameKeyAction: Equatable, Sendable {
    case move(rows: Int, columns: Int)
    case digit(Int)
    case erase
    case toggleInputMode
}

public enum KeyCommand {
    public static func action(for key: GameKey) -> GameKeyAction? {
        switch key {
        case .up: return .move(rows: -1, columns: 0)
        case .down: return .move(rows: 1, columns: 0)
        case .left: return .move(rows: 0, columns: -1)
        case .right: return .move(rows: 0, columns: 1)
        case .delete: return .erase
        case .text(let t):
            if t == " " { return .toggleInputMode }
            if t == "\u{7F}" || t == "\u{8}" { return .erase }
            if t.count == 1, let d = Int(t), (1...9).contains(d) { return .digit(d) }
            return nil
        }
    }
}
```

    /// Hardware keyboard: arrows, 1–9, Delete, Space. ⌘ shortcuts are left to the buttons.
    private func handleKey(_ press: KeyPress, _ s: Binding<GameSession>) -> KeyPress.Result {
        guard !s.wrappedValue.isPaused, !s.wrappedValue.isComplete, !press.modifiers.contains(.command) else { return .ignored }
        let key: GameKey
        switch press.key {
        case .upArrow: key = .up
        case .downArrow: key = .down
        case .leftArrow: key = .left
        case .rightArrow: key = .right
        case .delete, .deleteForward: key = .delete
        default: key = .text(press.characters)
        }
        guard let action = KeyCommand.action(for: key) else { return .ignored }
        switch action {
        case .move(let rows, let columns):
            s.wrappedValue.moveSelection(rows: rows, columns: columns)
        case .digit(let d):
            s.wrappedValue.input(d, settings: model.settings)
            changed(s.wrappedValue)
        case .erase:
            s.wrappedValue.erase()
            changed(s.wrappedValue)
        case .toggleInputMode:
            s.wrappedValue.inputMode = s.wrappedValue.inputMode == .normal ? .candidate : .normal
        }
        return .handled
    }
