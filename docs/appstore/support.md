# Really Really Hard Sudoku — Support

Found a bug, a puzzle that seems wrong, or a hint that didn't make sense?

- **Report it:** [open an issue on GitHub](https://github.com/jeffalipson/suduko-hard/issues/new) — include the mode (Classic or Killer), the tier, and a screenshot if you can.
- **Privacy:** see the [privacy policy](privacy-policy.html). The app collects no data.

### Common questions

**Is every puzzle solvable without guessing?** Yes. Every puzzle has exactly one solution and is graded by the hardest technique it needs.

**Why does a hint ask me to turn on Auto Pencil?** Most hints past singles remove candidates, which only makes sense when all of them are shown.

**Do hints and reveals affect my stats?** A game counts as a clean solve only with no hints, checks, reveals or assists.
